# Misinformation Early Warning Dashboard

## About the Project
A Python-based machine learning project that detects whether a news article is fake or real.

## Technologies Used
- Python
- Machine Learning
- NLP
- TF-IDF
- Naive Bayes
- HTML
- CSS
- JavaScript
- MySQL

## Features
- Fake and real news classification
- Text preprocessing
- TF-IDF feature extraction
- Machine learning prediction
- Prediction result with confidence percentage
- Prediction history

## How It Works
1. User enters the news text.
2. The text is preprocessed using NLP techniques.
3. TF-IDF converts the text into numerical features.
4. The trained Naive Bayes model predicts whether the news is fake or real.
5. The result is displayed to the user.

## Project Structure
- `app.py` – Main application
- `train_model.py` – Model training
- `model.pkl` – Trained model
- `vectorizer.pkl` – TF-IDF vectorizer
- `templates/` – HTML pages
- `static/` – CSS and static files
